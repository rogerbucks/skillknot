# Model tiers by vendor

Gauntlet names tiers, so it can run on any vendor's models. Add your vendor here, or set your own
map in the personal file at `~/.config/skillknot/gauntlet.md`.

- **Anthropic Claude:** fast Haiku, mid Sonnet, strongest Opus

**With only one model,** use it for every tier, and keep the blind judging and fresh critics. They
matter more than the tiers do.

**A local model** can build, and should not act as a critic or judge.

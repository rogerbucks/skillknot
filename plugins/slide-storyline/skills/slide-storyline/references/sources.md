# Where this design comes from

Written fresh for this repo. No text was copied from the sources below, which are well-known
methods in business writing and presentation design.

- **The pyramid principle.** Lead with the answer, then group the reasons beneath it. Associated
  with Barbara Minto's work on structured business writing
- **Situation, complication, resolution.** A common opening for an audience that does not yet
  feel the problem
- **Assertion-evidence slides.** A full-sentence claim as the headline, with visual evidence
  beneath it, studied in engineering and science communication
- **Plain-language practice.** Short sentences, the main point first, and the reader's own words

## Design choices

- **Story before design,** because a well-designed deck with no argument still fails
- **The headline test is the core check.** It is fast, anyone can run it, and it catches most
  weak decks
- **Hand over an outline, not slides,** so the skill works with any slide tool and stays vendor
  neutral
- **Never invent a number.** A gap marked as a gap is more useful to the presenter than a guess

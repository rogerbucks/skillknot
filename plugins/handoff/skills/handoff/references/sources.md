# Where this design comes from

These were written fresh for this repo from a method developed and used in one person's private agent setup. No text was copied from that setup or from the sources below, which were read on 1 Nov 2026.

- **Private use.** The design came from a measured gap: decisions were being written down at
  the end of sessions, but recommendations and next steps were not, and they were lost with the
  chat
- **One task, one file,** and generated roll-ups rather than shared hand-edited lists, so that
  two sessions never write the same file at once
- **Scope the report to the session,** because an unscoped list of every open task was ignored

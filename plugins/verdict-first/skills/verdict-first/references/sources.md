# Where this design comes from

These were written fresh for this repo from a method developed and used in one person's private agent setup. No text was copied from that setup or from the sources below, which were read on 1 Nov 2026.

- **[Claude Code output styles](https://code.claude.com/docs/en/output-styles).** The format of
  the bundled output style, including `keep-coding-instructions`
- **Plain-language practice.** Short sentences, and the main point first
- **Private use.** The style began as a fictional-character voice tuned for a reader with ADHD.
  This version keeps the habits that helped (verdict first, one recommendation, honest
  confidence bands, calm) and drops the character

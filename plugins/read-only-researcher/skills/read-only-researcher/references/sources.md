# Where this design comes from

These were written fresh for this repo from a method developed and used in one person's private agent setup. No text was copied from that setup or from the sources below, which were read on 1 Nov 2026.

- **[Claude Code subagents](https://code.claude.com/docs/en/sub-agents).** The agent file format
  and tool limits
- **Private use.** A researcher agent that was described as read-only but had write tools. This
  version removes them, so the limit holds whatever a web page says

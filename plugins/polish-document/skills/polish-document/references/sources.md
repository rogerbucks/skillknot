# Where this design comes from

These were written fresh for this repo from a method developed and used in one person's private agent setup. No text was copied from that setup or from the sources below, which were read on 1 Nov 2026.

- **[CommonMark](https://commonmark.org/).** The Markdown the format pass aims at
- **[Mermaid](https://mermaid.js.org/).** The diagram syntax for pass 4
- **Private use.** Gaps first, because once a document is formatted it looks finished and its
  gaps stop showing. Proposed sections stay marked, so the author's words and the agent's stay
  separable

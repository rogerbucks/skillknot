# Where this design comes from

These were written fresh for this repo from a method developed and used in one person's private agent setup. No text was copied from that setup or from the sources below, which were read on 1 Nov 2026.

- **Beneficial ownership,** as used in company-register and anti-money-laundering rules. The idea
  of an ultimate controller behind the registered owners
- **Private use.** The five passes, the "tell" test for behavioural claims, and the layout rules
  (the company is the box, its controller a fact inside it) came from building and revising real
  sector maps
